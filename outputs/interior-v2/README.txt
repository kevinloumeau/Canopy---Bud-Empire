CANOPY INTERIOR SPRITES V2
24 separate RGBA PNG sprites generated with the built-in image generation tool.
Cannabis foliage; ORDER and PICKUP counter labels; 2:1 isometric camera prompts.
Original assets are preserved. These are standalone replacements, not yet wired into the game.
manifest.json contains filenames, generation provenance, and the complete prompt set.
alpha-report.json contains PNG dimensions and alpha checks.
preview.jpg is a review sheet only and is not a game sprite.
