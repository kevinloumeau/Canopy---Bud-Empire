# Ground textures

5 seamless top-down textures, 512x512 PNG. Generated with Ludo `image create`, image type `texture`, Stylized 3D art style, Top-Down perspective, 4 candidates each.

Each pick was checked by tiling it 2x2 (see `previews/00-ground-tiled-2x2.jpg`); no seams are visible. The textures are square and top-down, so project them onto the 2:1 ground diamond in code.

- `ground.asphalt` is very smooth, with almost no speckle.
- `ground.kerb.stone` is rows of cream blocks rather than a single strip; crop one row if a single kerb line is needed.
