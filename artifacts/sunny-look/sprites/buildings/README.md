# Neighbour buildings (brief section 7)

5 transparent PNGs, generated with Ludo `image generate-with-style` (hero counter as style reference) plus the brief's "muted desaturated pastel walls, pale windows, very soft contrast, no signage" line. 4 candidates each.

None came out as tan or with a truly rounded corner. `building.low.tan` is the warmest of the four candidates, and `building.corner` has glazing on both faces but a square corner.
