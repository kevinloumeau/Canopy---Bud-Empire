# README artwork

These assets belong to the repository's GitHub README. They are local files so the presentation does not depend on an external screenshot host.

- `cover.svg`: the existing Canopy leaf, forest-green palette and Bricolage Grotesque lettering converted to vector outlines. It needs no web font or script to render.
- `main-shop.jpg`: the current main shop with three staffed counters and developed equipment.
- `riverside.jpg`, `old-town.jpg`, `city-center.jpg`, `desert-oasis.jpg`, `alpine.jpg`: matching captures of the five live branch scenes (`scripts/capture-branches.mjs`).
- `mobile-stations.jpg`: the current station interface at a 390 × 844 viewport.

Branch and main-shop screenshots were recaptured from the local dev build on September 22, 2026 (with the WebGL post pass: bloom, grade, grain), via `scripts/capture-branches.mjs`;  `mobile-stations.jpg` remains from September 19, 2026. All were captured using an isolated showcase save with unlocked branches and developed equipment. They show actual rendered gameplay, not concept art or a fresh player's starting state. The showcase save was removed after capture; the player's save was not used.

The brand typeface is [Bricolage Grotesque](https://github.com/ateliertriay/bricolage), licensed under the SIL Open Font License. Only the outlined cover artwork is included here.
